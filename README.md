# SWYNEX Data Cleaning Preparation

## Internship Task 1

This project is part of the SWYNEX Data Analyst Internship.

### Dataset
Titanic Dataset

### Objective
The objective of this task is to clean and prepare the Titanic dataset for analysis.

### Data Cleaning Performed

1. Checked for missing values.
2. Filled missing Age values using the median value (28).
3. Filled the missing Embarked value with the most common value (S).
4. Filled missing Cabin values with "Unknown".
5. Checked for duplicate records.
6. Checked data types of all columns.
7. Checked inconsistent values in Sex and Embarked columns.

### Result

The cleaned dataset is available in this repository as:

SWYNEX_Titanic_Data_Cleaned.xlsx

### Conclusion

The Titanic dataset was cleaned and prepared for further data analysis.
